Windows Setup

To work on this project on Windows:



1. Install Git for Windows and Visual Studio Code.
2. Open Git Bash.
3. Clone the team repository to your computer.
4. Go to the project folder using: cd \~/CIT240/cit240-team-project
5. Before starting new work, switch to the main branch and download the latest changes: git switch main git pull --ff-only origin main
6. Create or switch to your assigned feature branch before editing project files.

How to Open the Page

1.Open the project folder in Visual Studio Code.

2\. Find index.html in the project folder.

3\. Open index.html in a web browser to view the webpage.

4\. After making changes, save the file and refresh the browser to see the updated page.



Project Files

&#x09;The project contains the following files:

* index.html — Contains the main webpage and the group's welcome message and purpose.
* README.md — Contains project information, Windows setup instructions, and instructions for opening the webpage.
* team.md — Contains the five team members' names, GitHub usernames, and assigned tasks.
* workflow.md — Describes the team's Git and GitHub collaboration workflow.
* testing.md — Records the project's testing checks, actual results, and any issues found.
